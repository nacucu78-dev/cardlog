선택한 월 기준

    설정

    1. 이 화면의 역할

    이 화면은 팀원 모드로 사용합니다. 팀원은 자기 기록만 보이며, 동기화는 자기 기록을 시트에 올리기만 합니다. 아래에서 내 이름을 선택하고 저장하세요.

    관리자 전용 — 비밀번호 필요

    2. 팀원 명단

    사용자 선택 목록에 표시될 이름입니다. 12명 등 ENTER 키로 한 줄씩 추가하세요. 설정 저장 시 구글 시트로 명단이 공유되어 폰·PC 등 다른 기기에도 같은 명단이 표시됩니다(v12).

    기본 꺼짐 — 사용 시에만 표시

    구글 시트 연동 설정

    이 파일을 각자 컴퓨터에서 열면 기록이 각자 브라우저에만 저장됩니다. 함께 모아 보려면 아래 순서로 공유 구글 시트에 연결하세요. 연결 후 각자 「시트 동기화」 버튼만 누르면 전체 기록이 모입니다.

    1. 구글 드라이브에서 새 스프레드시트를 만들고, 확장 프로그램 → Apps Script를 엽니다.
    2. 아래 코드를 전부 붙여넣고 저장한 뒤, 배포 → 새 배포 → 웹 앱으로 올립니다.
    3. 웹 앱 설정: 실행 대상 = 나, 액세스 권한 = 있는 사용자 모두 → 배포 후 발급된 웹 앱 URL을 복사합니다.
    4. 아래 입력칸에 URL을 붙여넣고 저장합니다. 이 파일을 받는 팀원 컴퓨터에는 같은 URL이 미리 들어가 있습니다.

    이미 배포한 적이 있는 경우(URL 유지): 위 코드를 전부 덮어쓰기해 저장한 뒤 배포 → 배포 관리 → 연필(편집) → 버전: 새 버전 → 배포를 하세요. 주소는 그대로이고 팀원 명단 공유(v12)가 켜집니다.
